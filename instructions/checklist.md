# PR Checklist

### 🎨 Design Review

- [ ]  Clear visual hierarchy (page → section > content > details > meta) — **Guidelines 7.2, 1.10**
- [ ]  Labels and buttons have clear, action-oriented text — **Guidelines 8.1, 11.1**
- [ ]  Alignment and spacing consistent using system scale — **Guidelines 6.1, 6.4, 1.7, 1.8**
- [ ]  One clear primary CTA per screen/section — **Guideline 8.2**
- [ ]  Similar components look and behave the same — **Guidelines 7.1, 5.1, 1.6**
- [ ]  No duplicated information on page — **Guideline 7.3**
- [ ]  Interactions follow familiar patterns — **Guidelines 1.4, 1.6**

### 🛠 Engineering Review

- [ ]  Validation, error, and success states — **Guidelines 5.4.4, 8.4**
- [ ]  Loading and empty states — **Guidelines 9.1, 9.2, 9.3, 9.4, 9.5**
- [ ]  Data formatted correctly (dates, numbers, currency) — **Guideline 11.3**
- [ ]  Copy/paste support where applicable — **Guideline 11.4**
- [ ]  Keyboard navigation and focus states — **Guidelines 10.2, 10.3, 8.3**

### ♿ Accessibility & Compliance

- [ ]  Responsive across breakpoints (mobile-first) — **Guideline 10.1**
- [ ]  Only existing components, styles, tokens used — **Guidelines 4.1**
- [ ]  No new colors/sizes without system update — **Guidelines 4.2**
- [ ]  Icons use approved library and standard sizes — **Guidelines 5.3.1, 5.3.2, 5.3.3, 5.3.4**
